# BladeClient

**Blade Client for modern PvP.**

BladeClient is a lightweight client for Minecraft **1.21.8** built on the **Fabric** toolchain, focused on smooth PvP performance and a clean customizable UI.

## Info

| | |
|---|---|
| Version | `0.17.3-alpha` |
| Minecraft | 1.21.8 |
| Loader | Fabric (>= 0.18.4) |
| Java | 21+ |

## Features

- Custom **HUD** with draggable elements
- **Click GUI** with categories and keybinds (YetAnotherConfigLib + Owo-lib)
- **Freelook** & **Zoom**
- Custom **chat** enhancements
- **Skin / visual** customization options
- Built-in **AntiCrack** protection

## Dependencies

Installed automatically via Fabric:

- [Fabric API](https://modrinth.com/mod/fabric-api)
- [YetAnotherConfigLib](https://modrinth.com/mod/yacl)
- [Owo-lib](https://modrinth.com/mod/owo-lib)

## Building from source

```bash
./gradlew build
```

The built jar will be in `build/libs/`.

## Installation

1. Install the [Fabric Launcher](https://fabricmc.net/use/installer/) for Minecraft 1.21.8.
2. Drop the BladeClient jar (plus dependencies) into your `.minecraft/mods` folder.
